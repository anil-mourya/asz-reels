# asz-reels

Public media for A S Safetyzone Pvt Ltd Instagram reels, pushed by the Reels Studio agent and fetched by ASZ One (`upload_marketing_asset_from_url`) for publishing.

- `reels/YYYY-MM-DD-<slug>.mp4` — 1080x1920 H.264 + AAC
- `covers/YYYY-MM-DD-<slug>.jpg` — 1080x1920 cover
- `brand/logo.jpg` — company logo, on every frame
